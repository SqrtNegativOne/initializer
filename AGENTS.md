# Agents
Information about AI agents or autonomous scripts operating on this project should be documented here.

## Basic Facts
- **App Name**: Genesis (Initializer)
- **Framework**: `pywebview` with HTML/CSS/JS frontend and Python backend.
- **Functionality**: A desktop app that functions as a routine and checklist manager (e.g., Calibration, Surveillance, Quick job).

## Rules
- All static assets (fonts, sound effects, images) must be downloaded and stored locally in the `src/frontend/assets` folder. Do not use external/online links to avoid network dependency issues on startup.
